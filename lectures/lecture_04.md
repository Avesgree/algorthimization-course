# Занятие 4. Аннотации типов и документация кода

## Аннотации типов
* Строгая типизация с помощью составных типов (модуль `typing`).
* Статический анализ кода с использованием `Pylance` и `mypy`.

## Документация и линтинг
* Форматы докстрингов (PEP 257).
* Автоматическая проверка стиля и ошибок с помощью `Ruff`.
* Сборка документации проекта с помощью `Sphinx`.
