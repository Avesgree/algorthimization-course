# МДК.01.01 · Разработка программных модулей (2 курс, 2026/2027)

Репозиторий для учебного курса по разработке бэкенда на Python.

## Описание курса
* **Объем:** 218 часов (109 занятий по 2 часа)
* **Разделы:** 12 разделов
* **Стек технологий:** Python, FastAPI, PostgreSQL, Redis, Celery, Docker Compose, CI/CD.

## Структура репозитория

| Папка / Файл | Назначение | Что сдается в итоге |
| :--- | :--- | :--- |
| `lesson_01/` – `lesson_07/` | Практические занятия 1–7 | Отчеты, код и файлы заданий |
| `lectures/`, `materials/`, `docs/` | Теория, шаблоны и инструкции | — |

## Быстрый старт и развертывание
1. Клонируйте репозиторий: `git clone <url>`
2. Создайте виртуальное окружение: `python -m venv .venv`
3. Активируйте окружение (`.venv\Scripts\activate` или `source .venv/bin/activate`)
4. Установите утилиты: `pip install ruff mypy pytest`
